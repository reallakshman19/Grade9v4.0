Required: 12.7-inch tablet QA for Core2

Before each production deployment of the Physics/WPE Core2 Question Bank, open the actual first-class page at Question Bank directly—not in an iframe. Run tests on the exact commit and collect screenshots at the minimum CSS viewport sizes below. The physical 12.7-inch diagonal does not uniquely determine CSS pixels; test at known CSS viewport and DPR settings and record the device/browser used.

  1. Open direct URL and confirm document.querySelectorAll('iframe').length === 0.
  2. Confirm document.documentElement.scrollWidth <= innerWidth at all target sizes; inspect tables, math, figures and long source labels.
  3. Verify there is one site navigation and a clear Physics → WPE → Question Bank path; no duplicate app nav or nested page scrollbar.
  4. Open a real question with a long prompt/diagram, last question, filtered question and an empty filter result; check Previous/Next, search, source filter and proposed-band filter.
  5. Enter an answer, commit the local attempt, reveal hints in order, reveal the author-proposed solution deliberately; ensure key text does not leak before the permitted step.
  6. Verify keyboard focus, selectable text, visible tab controls, minimum touch targets ~44 CSS px and readable contrast; test actual on-device zoom if available.
  7. Record screen dimensions, DPR, browser version, page SHA, screenshots, browser console failures, pass/fail disposition and remaining NOT_RUN. Device testing cannot be inferred from a stylesheet review.
Core2 UI no-go: iframe inside a second scrolling page, side-by-side content too narrow to read, inaccessible buttons, viewport overflow, or unrecoverable navigation. Fix and retest before a claim of technical production readiness.
