Student learning architecture · WPE Physics pilot

Which tiles belong to Core1A, Core1B and Core2?

Learn → Challenge is the way in—not a fourth Core. The three Core roles describe what the learner does. One lesson page can contain both Core1A explanation and Core1B independent practice. The Question Bank remains Core2.

Core2 · Original question→ Core1A · Learn→ Core1B · Challenge→ Core2 · Try again

This is a learner navigation path, not an academic approval sequence or a replacement for source, QRT, Blueprint and adapter governance.

Shared gateway · Orchestration, not a Core

🧭 Learn → Challenge

Start from an exact Question Bank ID or explore a Physics skill. The gateway recommends a relevant teaching journey, explains whether it is a close match or related practice only, and returns the child to the same original question.

📚 Original Question Bank

Read the original source question, give an independent answer, and return after learning. Protect the source attempt and answer reveal; never replace the original problem with a practice version.
