How this progress is saved

In alignment with Grade9 v4.0 architecture, this public Alpha preview adheres to the following client-side data boundaries:

  • No User Identification: The app JavaScript requests no learner identity or credentials and does not transmit the learner explanation. Hosting providers can still process server access logs and IP addresses.
  • Ephemeral Session Memory: Progress flags, selected answer, and timestamp are stored in sessionStorage where supported; no explanation text is saved. Reset clears this app state. Browser session lifetime depends on browser behavior.
  • Local Calculations: The slider and attempt-length check run locally. The explanation is not automatically judged for physics correctness. Static resource requests may reach the host when viewed over HTTP.
