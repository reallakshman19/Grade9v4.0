# Source → construction preparation, R2

Use this route for a chapter, syllabus or collection whose coverage denominator matters. This is a companion to SL1/SL2, not SL3. It produces an inspectable author input and review requests, not scientific qualification or a course.

## Workflow and completion

1. Freeze the actual scope source and retain the originals. Derive the node list from its saved rows rather than an invented fixed count. Give every retained book line an intake disposition: source section, shared context, extraction metadata or derived summary. Accounting for a line does not mean teaching or endorsing it. Excluded/missing source material remains visible.
2. Identify exact passages, source scans and derived figures separately. Preserve verbatim units and source hashes. A page visual observation names its region, what was actually seen and its limits. It is not OCR acceptance or scientific review. Record discrepancies without changing the source bytes.
3. Interpret source-bound claims with conditions and disputes. Separate candidate canonical matches by DIRECT_CANDIDATE, PREREQUISITE_BRIDGE or SCOPE_NEARBY. A nearby capability must never be presented as the missing primary capability. If a decisive warrant is absent, create a MISSING warrant group with no invented unit reference.
4. Specify the intellectual construction: inputs/output, obstacle, decisive bridge, prerequisites, conventions, steps/dependencies, representations and why each step is needed. Bind each consequential claim and warrant requirement. Do not force six steps or a specific algorithm on all future subjects; the WPE examples use six roles because those obligations are useful there.
5. Carry explicit conditions/boundaries, plausible wrong-path hypotheses, a discriminating contrast and a required repair. No actual learner observation exists unless separately supplied; these records deliberately say NONE. Describe independent-check methods, invariants and their proposed independence basis as DESIGN_ONLY.
6. Bind the required native authoring properties to actual retained schema definitions. This is an authoring target map, not a native package or acquisition receipt. A missing native record/representation is not filled with an empty approved-looking object.
7. Prepare exact-digest review requests for every claim, warrants, construction and SL2 join. Obtain independent scientific/cognitive judgments through their real native task and authority. A book node has no examination band. Missing reviewed SL2 evidence leaves an explicit pending join; it does not invalidate honest source intake.
8. Validate integrity, retain an externally conveyed expected program digest, render all dossiers and reconcile source/node gaps. Deliver JSON, the author HTML view, evidence/pin receipts and exact archive identity. Preserve author exposure and unexecuted checks. Do not call candidate completion course acceptance.

**Preparation completion:** every actual scope node and source line has an honest disposition; each node has evidence-bound claims, candidate/missing warrants, construction obligations, repair/check designs, native targets and version-bound review requests. A missing scientific warrant is a legitimate gap-bearing output, not permission to teach. `10/10 accounted` never means ten scientifically complete constructions.

This is an explicit integration boundary, not an implemented registry or promotion engine.

## Trust and invalidation

Per-record pin sets bind exact expected source records, and program entries bind record/pin bytes. `--expected-sha256` anchors the entire program to a separately conveyed receipt. Without that anchor, per-record pins can agree inside an entirely replaced self-declared program. Even an external match authenticates expected local bytes only; it does not authenticate a publisher, official exam or scientific conclusion.

Changing any source/span, node requirement, review target, record or program requires refreshed derived hashes and review of affected semantic dependencies. The checker detects stale bytes, target digests, unresolved references and cycles. It does not infer what changed scientifically. A coherent false claim with consistently refreshed hashes can pass mechanical checks; science remains NOT_RUN and authoring HOLD. Keep that regression as a surviving-error challenge.
