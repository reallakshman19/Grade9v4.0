# Package architecture

P0.1 validates JSON schemas, references, prerequisites and numeric demand scores. Future P0.2–P0.4 will add hashing, reviewer receipts, B1–B7 and governance gates. No scientific, cognitive, source authenticity or student-release certification is inferred from green CI.
