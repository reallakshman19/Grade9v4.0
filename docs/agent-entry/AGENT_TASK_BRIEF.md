# Task brief for an agent with no chat memory

Use this as a task-specific handoff outline, not an authorization or new engineering protocol.

- Parent aim and user-visible result; actual subject/topic/construction scope.
- Owner's exact task/role designation, writer custody, resource bound/start/deadline; no inherited closed grants.
- Read Start_here and 00-required-reading; exact current companion and relevant original methodology/report sections.
- Exact inputs and SHA pins: source/stem/key/figures, skill version, subject Blueprint, selected adapter (or unresolved choice), library, schema, renderer, candidate IDs and output paths.
- Source types/counting identity; reviewed versus inherited proposals; critical corrections and supersession links. For independent review supply source-only task packet and seal first pass before author/key exposure.
- Kept behavior/content, requested changes, native contract fields and consumer; distinguish evidence preparation from lessons and academic approval.
- Done-when criteria and necessary author checks/negative controls; distinct review and Owner gates that cannot be self-issued.
- Private/public custody; no remote write, installation, agent launch, promotion or release without its actual grant.
- Return exact artifact paths/hashes, commands/results/failures/NOT_RUN, decisions and reasons, pending evidence and next actor. No whole-chat replay needed.

An incomplete source, wrong operation or missing warrant must remain explicit at the affected boundary. Optional P1 absence does not block learning. D3.1 remains paused unless the Owner explicitly resumes it.

Fresh blind academic reviewers start with [the source-only entry](07-independent-review.md) instead of author-exposed common outcomes.
