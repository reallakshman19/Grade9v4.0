# Smart Labelling 1: source identity and fitness

Establish what the question is, where it came from, what is trustworthy and whether a fair optional first attempt is possible. Preserve the Owner's source bytes and existing v1 overlays. This candidate adds a derived v2 evidence contract; it does not install itself or change the Physics Blueprint.

Read [record-shape.md](references/record-shape.md) before writing v1 records. Read [hardening-contract.md](references/hardening-contract.md) before preparing or checking v2 bindings, provenance, review or readiness.

## Work from sources

- Read exact saved stem, options, format and figures. Keep authority separate from discovery site. Record original ID, paper/locator, version, parent variant and duplicate relationships. An authored transfer has a separate identity; a reusable family does not merge tasks.
- Bind question payload/figure assets and publisher or official answer evidence separately. The legacy question digest does not bind every real source field or key. Use a declared source adapter and current artifact hashes; absent extraction stays unsupported. Official paper and official key each need their own custody and independent review.
- Map subject, topic, microtopics, capability, concept badge, stage, prerequisites and family using the pinned library/vocabulary. Preserve cross-topic prerequisites and visible missing links. Concept difficulty is the library badge, not the question's intrinsic demand band.
- Work the answer independently, then compare with the resolved reference. Record disagreements, ambiguity, option cues, figure fitness, duplication and rights. Essential missing figures and doubtful answers block first-try readiness. Exam/book passages remain Owner-local.
- Give the learner only the start card: requested task, context and no hints. Keep answers, decisive moves, evidence digests and reviewer material out of it. Preserve existing teaching/assessment; intake is not permission to rewrite lessons.

## Deliver and check

Write derived labels only to the authorized candidate/output location. New labels remain UNREVIEWED. REVIEWED requires a current, distinct trusted reviewer receipt, not an enum. Do not claim VERIFIED from a publisher label or merely seeing a reference path.

Prepare a new v2 snapshot, then select the needed gate with `scripts/check_sl1.py`; commands and shapes are in the contract reference. Legacy validation remains available only through explicit `--legacy-only` and grants no qualification. `--allow-partial-practice` requires actual Owner policy; honest partial practice does not count as authenticated exam coverage. P1 remains optional.

Carry unresolved source/key/authority gaps to SL2/QRT with exact dependencies. Changed inputs are rechecked and stale promotions held. Never mark old observations independent or refresh a pin to conceal a changed question/key.
